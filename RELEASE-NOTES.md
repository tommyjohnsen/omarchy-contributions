# v0.1.0 — experimental contribution collection

Eleven reviewed source/patch packages for Omarchy desktop behavior, Vulkan integration and read-only Immich file access. See README.md for the package index, authorship, independent-review scope and licensing.

This prerelease preserves exact staged package bytes, upstream notices and per-package provenance. It is not an automatic installer, a compatibility guarantee for current upstream HEAD, or an upstream-accepted release. Follow each package's documented baseline, installation prerequisites and remaining runtime limitations.

Publication authorized by Tommy Johnsen on 2026-11-10. Codex prepared this collection; Claude Code, Grok Build and Google Gemini supplied the recorded static reviews. No new model review or full runtime test suite is claimed for these supplemental packaging files.

Excluded: Nextcloud (outstanding review findings), historical floating-window workaround, newer unreviewed desktop fixes, and Meetmate.
