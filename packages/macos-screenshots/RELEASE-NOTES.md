# Opt-in macOS screenshot shortcuts

The preset maps Command+Shift+3 to a saved full-screen screenshot and Command+Shift+4 to saved region selection. It replaces the workspace-3/4 move chords only when enabled. The exact snippet and source/CLI context were reviewed by Claude Code, Grok Build and Google Gemini; their no-blocking-findings verdicts are static assessments.

Codex verified binding and CLI contracts; the user confirmed the configured shortcuts in this setup. Other keyboard layouts, region cancellation, and double reload against the target upstream branch remain explicit integration checks. Ship as an optional preset rather than a new global default.
